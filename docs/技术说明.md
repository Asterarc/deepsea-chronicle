# 技术说明

## 运行架构

浏览器使用原生 Canvas 和 ES Modules；Node.js 核心 HTTP 模块提供 API，JSON 文件存储世界。没有前端构建流程、数据库服务、外部字体或在线 AI API。

`web/sprites.js` 是鱼的唯一绘图来源，由浏览器和 Node 视频渲染器共用。`lib/world.mjs` 负责纯数据规则，`lib/store.mjs` 负责读取、备份及串行原子写入，`lib/episode.mjs` 负责选材与审核，`lib/video.mjs` 负责音视频生成。

## 主要接口

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/world` | 完整世界快照 |
| GET | `/api/status` | 运行状态和编码器状态 |
| POST | `/api/tick` | 推进 1–30 天 |
| POST | `/api/event` | 触发具名事件 |
| POST | `/api/adopt` | 创建本地居民 |
| POST | `/api/expeditions` | 发起远征并公示名单 |
| POST | `/api/expeditions/:id/cancel` | 取消集结 |
| POST | `/api/expeditions/:id/depart` | 反悔窗口后手动出发 |
| GET/POST | `/api/episode` | 获取／重新生成当天纪事 |
| POST | `/api/episode/review` | 保存五项审核结果 |
| POST | `/api/votes` | 校验并保存当天投票 |
| POST | `/api/render` | 后台导出样片或正片 |
| GET | `/api/render/:id` | 查询进度与结果 |
| GET | `/api/files` | 导出文件列表 |
| GET | `/api/world/download` | 下载完整世界备份 |

正文 JSON 限制 1MB。服务只监听本机回环地址；写操作拒绝跨来源请求；导出文件路由不允许目录穿越。

## 数据约定

`residents.id` 是永久居民编号，`residents.currentFishId` 指向当前世代。`fish` 保存全部世代，`relationships.a/b` 和 `actionLog.fishId` 均引用永久编号。远征保留完整参与者名单、出发日期、归航者及孵化者列表。

随机状态保存为 `rngState`，同一初始种子及操作序列能够复现。每日演化不依赖系统日期；本地按钮明确推进模拟时间。

生成纪事不会改变世界。只有正片成功生成才按当天幂等记录上镜次数；重新生成与审核分别保存到当天 JSON 和 Markdown。

## 部署边界

本地版只有一个服务进程。进程内写操作排队，不支持多个服务进程同时修改同一世界。多人运营时需要替换存储层并接入身份校验、真实授权、真实时间的远征窗口及平台接口。

静态目录和导出目录均为本机资源，没有公网发布和账号凭据。网络仅用于首次安装 npm 依赖；安装完成后可离线运行。
